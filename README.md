# 🍬 魔法菓子工房（仮）

パステル基調のお菓子ワールドで、ジェリー・キャンディ・シロップの色をジャーごとに揃えていくカラーソートパズル。
ルールは「同じ色の上には同じ色しか置けない」の1つだけ。PWA対応で、ホーム画面に追加してアプリのように遊べます。

---

## 🎮 ゲームの遊び方

1. 色を移動させたいジャーを**タップ**して選ぶ
2. 移動先のジャーを**タップ**すると、選んだジャーの一番上の色のかたまりが注がれる
3. 注げる条件は「移動先が空っぽ」または「移動先の一番上と同じ色」のときだけ
4. すべてのジャーが「空っぽ」か「同じ色でいっぱい」になったらレベルクリア
5. 手数が少ないほど獲得できる★が増え、ヒント等のアイテムを使わずにクリアすると「ノーアイテムボーナス」も獲得

選んだジャーが注げる相手は緑色に光るので、次の一手が分かりやすくなっています。

---

## ✨ 主な機能・システム

- **無限レベル生成**：色をランダムに配置したうえで、実際に解けるかを内部で検証してから出題（生成のたびに解けることを保証）
- **難易度カーブ**：レベルが進むごとに使用色数が4→最大8色まで増加
- **🔒 ロックジャー**：レベル5以降、一部のジャーがロック状態で登場。ほかの色を1つ完成させると解除される
- **★スコアリング**：手数に応じて★1〜3、ノーアイテムクリアで追加ボーナス
- **ヒント／シャッフル／ボトル追加**：ショップでゴールド購入 → 所持数を消費して使用、なくなったら都度ゴールドで購入
- **📋 デイリーミッション**：3種のミッション（レベルクリア／ヒント使用／ゴールド獲得）、日付が変わると自動リセット
- **🎁 ログインボーナス**：日替わりで受け取り可能、日数が増えるほど報酬アップ
- **🏆 オンラインランキング**：Firebase連携で最高到達レベルを世界中のプレイヤーと共有（未設定時はローカルのサンプル表示にフォールバック）
- **💾 進行状況の自動保存**：ゴールド・レベル・ミッション・プレイ中の盤面まで `localStorage` に保存。ページを再読み込みしても続きから再開できる
- **📱 PWA対応**：ホーム画面に追加してアプリのように起動可能（オフラインキャッシュは未実装、今後追加予定）
- **🔊 簡易SE**：Web Audio APIによる操作音（音声ファイル不要）、ミュート切り替え対応
- **あそびかたガイド**：初回プレイ時に自動表示、右上の「？」からいつでも再確認可能

## 🚀 セットアップ手順

### ① GitHubリポジトリを作成

1. [github.com](https://github.com/) にログイン
2. 右上の「+」→「New repository」
3. Repository name を入力（例：`magic-candy-workshop`）
4. **Public** を選択 →「Create repository」

### ② ファイルをアップロード

リポジトリページで「Add file」→「Upload files」から、以下を全てドラッグ＆ドロップし「Commit changes」：

```
index.html
firebase.js
manifest.json
README.md
```

### ③ アイコン画像をアップロード

以下もリポジトリの**ルート直下**に、フォルダを作らずそのままアップロードしてください。

```
icon-58.png
icon-80.png
icon-87.png
icon-120.png
icon-180.png
icon-192.png
icon-512.png
icon-1024.png
```

> ⚠️ `icons/` のようなフォルダは作らないでください。`index.html` と `manifest.json` はルート相対パスで参照しています。

### ④ GitHub Pagesを有効化

1. リポジトリの「Settings」タブ
2. 左メニュー「Pages」
3. Source を **「Deploy from a branch」→「main」→「/(root)」** に設定
4. 「Save」をクリック

数分後、以下のURLでアクセスできます：

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

### ⑤ 更新方法（ブラウザのみ）

1. GitHubのリポジトリページでファイルをクリック
2. 右上の「…」→「ファイルを編集」
3. 内容を編集 →「Commit changes」
4. 数分後に自動的に反映 ✅

複数ファイルをまとめて更新する場合は、「Add file」→「Upload files」で対象ファイルを一括ドラッグ＆ドロップし、1回のコミットでまとめて反映するのがおすすめです。

## 📱 ホーム画面への追加（PWA）

**iPhoneの場合**
1. SafariでゲームのURLを開く
2. 下部の共有ボタン（□↑）をタップ
3. 「ホーム画面に追加」→「追加」

**Androidの場合**
1. ChromeでゲームのURLを開く
2. 右上「⋮」→「ホーム画面に追加」→「追加」

## 🔥 Firebase ランキング設定（任意）

ランキング機能は Firebase を設定しなくても動作します（未設定時はサンプルデータ＋自分の記録のみのローカル表示になります）。世界中のプレイヤーとランキングを共有したい場合は、以下の手順で設定してください。

1. **Firebaseプロジェクト作成**：[Firebase コンソール](https://console.firebase.google.com/) → 「プロジェクトを追加」（Googleアナリティクスはスキップ可）
2. **Firestoreデータベースの作成**：左メニュー「Firestoreデータベース」→「データベースを作成」→ テストモード／`asia-northeast1`（東京）推奨
3. **設定値の取得**：歯車アイコン →「プロジェクトの設定」→「アプリを追加」→ `</>`（Web）→ 表示された `firebaseConfig` をコピー
4. **`firebase.js` に貼り付け**：

```javascript
const firebaseConfig = {
  apiKey:            "AIza...",
  authDomain:        "your-project.firebaseapp.com",
  projectId:         "your-project",
  storageBucket:     "your-project.appspot.com",
  messagingSenderId: "123456789",
  appId:             "1:123:web:abc..."
};
```

5. **Firestore セキュリティルール（推奨）**：Firebase コンソール → Firestore →「ルール」タブで以下に変更

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /scores/{doc} {
      allow read: if true;
      allow write: if request.resource.data.score is number
                   && request.resource.data.name is string
                   && request.resource.data.name.size() <= 12;
    }
  }
}
```

設定後、レベルクリアで自己ベストが更新されるたびに自動でスコアが送信され、ランキング画面が上位20件のオンラインデータを表示するようになります。

## 💾 進行状況の保存について

ゴールド・レベル・ミッションの進捗・プレイ中の盤面（途中のジャーの状態）は、ブラウザの `localStorage` に自動保存されます。同じブラウザ・同じ端末であれば、ページを閉じたり再読み込みしても続きから再開できます。

- ブラウザのプライベート（シークレット）モードや、ストレージがブロックされた環境では保存は無効になります（エラーにはならず、その場合はセッション内のみの進行になります）
- 保存はブラウザ単位のため、別の端末・別のブラウザとは共有されません（プレイヤー間で進行を共有したい場合はランキング機能をご利用ください）
- デイリーミッションとログインボーナスは、端末の日付が変わるタイミングで自動的にリセットされます

## 🛠 使用技術

| 技術 | 用途 |
|---|---|
| Vanilla JavaScript | ゲームロジック・パズル生成・UI制御（フレームワーク不使用） |
| Web Audio API | 操作音・クリア音（音声ファイル不要） |

| PWA (Web App Manifest) | ホーム画面への追加・アプリアイコン表示 |
